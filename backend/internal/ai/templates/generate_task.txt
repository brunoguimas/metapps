## ESTRUTURA DO JSON

```json
{
  "type": "quiz" | "essay",
  "meta": {
    "title": "Título descritivo e específico",
    "description": "Breve descrição do que a tarefa avalia",
    "expectations": "O que o usuário será capaz de fazer após concluir"
  },
  "content": {}
}
```

`content` deve seguir UM dos dois schemas abaixo, dependendo do `type`.

### QUIZ (para memorização e prática objetiva)

Use quando houver dificuldade em memorização OU desempenho recente baixo. Schema obrigatório:
{{.QuizSchema}}

Requisitos obrigatórios:
- 1+ questões; cada questão com **exatamente 4 alternativas**
- `answer` é índice inteiro 0-3, nunca string
- `explanation` obrigatória em cada questão
- Evite ambiguidade — apenas uma resposta correta
- Inclua `material` quando adicionar contexto for útil

### ESSAY (para raciocínio e domínio conceitual)

Use quando houver dificuldade em entendimento OU desempenho recente alto. Schema obrigatório:
{{.EssaySchema}}

Requisitos obrigatórios:
- `min_words ≥ 50`; `max_words ≤ 500`; `min_words < max_words`
- `instructions` deve orientar estrutura: introdução (tema e tese), desenvolvimento (argumentos com evidências), conclusão (síntese)
- Deve indicar claramente o que o usuário deve argumentar ou explicar
- Promova análise e pensamento crítico, não descrição genérica

## REGRAS DE QUALIDADE (CRÍTICAS — VIOLAÇÕES CAUSAM REJEIÇÃO)

1. **Personalização real**: Conteúdo deve ser específico ao tópico e dificuldades do usuário. NUNCA conteúdo genérico como "Explique sobre X".
2. **Coerência total**: objetivo → dificuldades → desempenho → tipo de tarefa → conteúdo específico.
3. **Nível de desafio apropriado**: Se desempenho baixo, foque em fundamentos e perguntas diretas. Se desempenho alto, inclua interpretação e combinação de conceitos.
4. **Expectations micro-específicas** e mensuráveis, não vagas como "aprender sobre X".
5. **NÃO repita** tarefas anteriores idênticas.
6. **Sem campos extras** além do que o schema permite.

## VERIFICAÇÕES FINAIS OBRIGATÓRIAS

Confirme que TODOS os itens são satisfeitos antes de retornar:
- [ ] JSON puro e válido, sem texto adicional
- [ ] `type` é exatamente `"quiz"` ou `"essay"` (minúsculo)
- [ ] `meta.title` ≥ 3 chars; `meta.description` ≥ 10 chars; `meta.expectations` específica
- [ ] `content` segue exatamente o schema do tipo escolhido
- [ ] Sem campos extras além do schema
- [ ] Se quiz: 4 alternativas por questão; `answer` índice 0-3; `explanation` presente
- [ ] Se essay: 50-500 palavras; `min_words < max_words`; instruções orientando estrutura argumentativa
- [ ] Conteúdo específico ao tópico, não genérico
- [ ] Foco nas habilidades com pior desempenho
- [ ] Coerência entre objetivo, dificuldades, desempenho e conteúdo

Se QUALQUER item for NÃO, corrija ANTES de retornar.
